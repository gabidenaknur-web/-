- Әрбір аппараттың өз атауы болсын.

- Құбырлар аппараттарды бір-бірімен дұрыс жалғастырсын.
- Мұнайдың қозғалысы сары-қызғылт түсті анимациямен көрсетілсін.
- Газ көк түспен көрсетілсін.
- Су көгілдір түспен көрсетілсін.

- Қажет болған жағдайда жабдықты басқанда ақпараттық терезе ашылсын.

2. НЕГІЗГІ ТЕХНОЛОГИЯЛЫҚ СЫЗБАНҰСҚА

Барлық жабдықтарды төмендегі ретпен орналастыр.

1-кезең. МҰНАЙ КЕН ОРНЫ
- Мұнай қабаты (жер астындағы резервуар).
- Мұнайлы қабаттың геологиялық көрінісі.
- Мұнай, газ және қабат суының қабатта орналасуы.
- Мұнай өндіретін пайдалану ұңғымасы.

2-кезең. ҰҢҒЫМА ЖӘНЕ ӨНДІРУ ЖҮЙЕСІ
- Өндіру ұңғымасы.
- Шегендеу құбырлары.
- Сораптық-компрессорлық құбырлар.
- Тереңдік сорап (ЭЦН).
- Ұңғыма сағасы.
- Фонтандық арматура.

3-кезең. ЖИНАУ ЖӘНЕ ТАСЫМАЛДАУ
- Мұнай-газ қоспасын жинау құбыры.
- Өндірістік манифольд.
- Қысым өлшегіш манометр.
- Шығын өлшегіш.
- Реттегіш арматура.

4-кезең. МҰНАЙДЫ АЛҒАШҚЫ ӨҢДЕУ
- Қыздырғыш пеш.
- Үш фазалы сепаратор.
- Мұнай мен газды бөлу.
- Қабат суын бөлу.
- Тік сепаратор немесе көлденең сепаратор.
- Қажет болған жағдайда қосымша тұндырғыш.

5-кезең. МҰНАЙДЫ СУСЫЗДАНДЫРУ ЖӘНЕ ТҰЗСЫЗДАНДЫРУ
- Мұнайды қыздыру блогы.
- Электродегидратор.
- Мұнайды сусыздандыру аппараты.
- Тұзсыздандыру блогы.
- Судың жеке шығу желісі.

6-кезең. МҰНАЙДЫ САҚТАУ
- Дайын мұнай резервуары.
- Деңгей өлшегіш.
- Температура датчигі.
- Қысым бақылау жүйесі.

7-кезең. ДАЙЫН ӨНІМДІ ТАСЫМАЛДАУ
- Мұнай айдау сорабы.
- Магистральдық құбыр.
- Мұнайды тасымалдау желісі.
- Дайын тауарлық мұнайдың шығуы.

ҚОСЫМША ТАРМАҚТАР:

А) Газды өңдеу желісі:
Үш фазалы сепаратор → газ жинау құбыры → газ компрессоры → газды өңдеу блогы → газ құбыры.

Ә) Қабат суын өңдеу желісі:
Үш фазалы сепаратор → су жинау құбыры → су тазарту блогы → су резервуары → қабатқа қайта айдау сорабы.

3. СЫЗБАНҰСҚАНЫҢ ОРНАЛАСУЫ

Барлық жабдықтарды технологиялық процестің жүру бағыты бойынша солдан оңға қарай орналастыр.

Сызбанұсқа мынадай логикамен орналасуы керек:

МҰНАЙ ҚАБАТЫ
↓
ӨНДІРУ ҰҢҒЫМАСЫ
↓
ҰҢҒЫМА САҒАСЫ
→ ЖИНАУ МАНИФОЛЬДЫ
→ ҚЫЗДЫРҒЫШ
→ ҮШ ФАЗАЛЫ СЕПАРАТОР
→ ЭЛЕКТРОДЕГИДРАТОР
→ ДАЙЫН МҰНАЙ РЕЗЕРВУАРЫ
→ АЙДАУ СОРАБЫ
→ МАГИСТРАЛЬДЫҚ ҚҰБЫР

Сепаратордан:
- Газ жеке тармақпен жоғары қарай бағытталсын.
- Су жеке тармақпен төмен қарай бағытталсын.
- Мұнай негізгі технологиялық желі бойынша әрі қарай қозғалсын.

Сызбанұсқа экранға сыймаса, көлденең бағытта жылжыту мүмкіндігі болсын. Бірақ барлық аппараттар мен байланыстар өз орындарында қалсын.

4. АНИМАЦИЯЛАР

Анимация сайттың ең маңызды бөлігі болып табылады.

Міндетті түрде мыналарды жаса:

- Мұнай құбырдың ішінде үздіксіз қозғалып тұрсын.
- Газ өз құбырында бөлек қозғалсын.
- Су өзінің құбырында қозғалсын.
- Сепаратордың ішінде мұнай, газ және су фазаларының бөлінуі визуалды түрде көрсетілсін.
- Резервуардың ішіндегі мұнай деңгейі көрініп тұрсын.
- Сорап жұмыс істеп тұрған кезде қозғалыс эффектісі болсын.
- Құбырлар бойымен ағын бағытын көрсететін қозғалмалы стрелкалар болсын.
- Жабдықтар жұмыс істеген кезде жарық индикаторлары жансын.
- Әрбір технологиялық кезең ретімен іске қосылсын.

Анимациялар CSS және JavaScript арқылы орындалсын. SVG элементтерінің қозғалысын пайдалан.

6. ИНТЕРАКТИВТІЛІК

Әрбір жабдықты басқан кезде жеке ақпараттық терезе ашылсын.

Мысалы:

«Үш фазалы сепаратор»

- Қызметі: мұнай-газ қоспасын газ, мұнай және су фазаларына бөлу.
- Жұмыс принципі: гравитациялық тұну және фазалардың тығыздық айырмашылығына негізделген бөлу.
- Кіріс: мұнай, газ және су қоспасы.
- Шығыс: бөлінген мұнай, газ және су.

«Электродегидратор»

- Қызметі: мұнай құрамындағы судың қалдық мөлшерін төмендету.
- Жұмыс принципі: электр өрісінің әсерінен су тамшыларының бірігуі және тұнуы.

«Мұнай сорабы»

- Қызметі: мұнайды құбыр арқылы айдау.
- Жұмыс принципі: механикалық энергияны сұйықтық ағынының энергиясына айналдыру.

Барлық жабдықтар туралы ақпарат қазақ тілінде болсын.
